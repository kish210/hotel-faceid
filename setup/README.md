# Hotel Face-ID — نسخه 0.9.0 (آزمایشی)

این نصب‌کننده کل سامانه **تشخیص چهره و مدیریت ورود/خروج هتل** را روی سیستم
مقصد نصب می‌کند. سورس کامل پروژه همراه نصب می‌شود تا در صورت بروز خطا بتوانید
مستقیماً آن را بررسی/تغییر دهید.

## پیش‌نیازها

- **ویندوز 10/11** (64 بیتی)
- **Docker Desktop** نصب و در حال اجرا (برای بالا آوردن کانتینرها)
  - دانلود: https://www.docker.com/products/docker-desktop/

> اگر Docker Desktop نصب نیست، نصب‌کننده در پایان، لینک دانلود را باز می‌کند.

## نصب

1. فایل `Hotel-FaceID-Setup-0.9.0.exe` را اجرا کنید.
2. مسیر نصب را انتخاب کنید (پیش‌فرض: `C:\HotelFaceID`).
3. پس از پایان نصب، از دسکتاپ **"Hotel Face-ID (راه‌اندازی)"** را اجرا کنید.

اسکریپت راه‌اندازی:
- `.env` را از `.env.example` می‌سازد (اگر وجود نداشته باشد) و رمزهای
  پیش‌فرض را با مقادیر تصادفی امن پر می‌کند.
- در صورت اشغال بودن پورت‌های ۵۴۳۲/۴۰۰۰ از شما می‌پرسد و پورت دیگری می‌گذارد.
- کانتینرها را build و بالا می‌آورد.

## پس از نصب

| آیتم | مقدار |
|---|---|
| پنل مدیریت | http://localhost:4000 |
| مستندات API | http://localhost:8000/docs |
| ورود اولیه | `admin` / `admin` — پس از اولین ورود تغییر دهید |

## ساختار نصب‌شده

```
C:\HotelFaceID\
├── docker-compose.yml      ← تعریف سرویس‌ها
├── .env                    ← تنظیمات (خودکار ساخته می‌شود)
├── services\               ← سورس کامل بک‌اند و سرویس چهره
│   ├── api\                ← FastAPI
│   └── face-service\       ← تشخیص چهره (InsightFace)
├── web\                    ← سورس کامل پنل React
├── db\init\                ← اسکیمای پایگاه داده
└── scripts\
    ├── start.ps1           ← بالا آوردن سامانه
    ├── stop.ps1            ← پایین آوردن سامانه
    ├── status.ps1          ← وضعیت کانتینرها
    ├── logs.ps1            ← مشاهده لاگ‌ها (دریافت زمان واقعی)
    └── debug.ps1           ← جمع‌آوری لاگ‌ها و اطلاعات عیب‌یابی در یک پوشه
```

## اسکریپت‌های کاربردی

```powershell
.\scripts\start.ps1     # اجرا / به‌روزرسانی سامانه
.\scripts\stop.ps1      # توقف سامانه
.\scripts\status.ps1    # وضعیت سرویس‌ها
.\scripts\logs.ps1      # لاگ زنده‌ی همه سرویس‌ها
.\scripts\debug.ps1     # بسته لاگ برای ارسال به توسعه‌دهنده
```

## عیب‌یابی

- **"Docker not running"**: Docker Desktop را باز کنید و منتظر بمانید تا سبز شود،
  سپس دوباره `start.ps1` را اجرا کنید.
- **خطای پورت اشغال**: `status.ps1` را ببینید؛ در `start.ps1` پورت جدید بدهید
  یا در `.env` مقادیر `WEB_PORT`/`POSTGRES_PORT` را عوض کنید.
- **هر خطای دیگری**: `.\scripts\debug.ps1` را اجرا کنید و پوشه خروجی را برای ما
  بفرستید. سورس کامل در دسترس است و خطای خط مربوطه قابل بررسی است.
