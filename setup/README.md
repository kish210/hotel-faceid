# Hotel Face-ID — نسخه 1.3.0

سامانهٔ تشخیص چهره و مدیریت ورود/خروج هتل.

این بسته **همه‌چیز را همراه خود دارد**: موتور اجرا، همهٔ کتابخانه‌ها و
مدل‌های تشخیص چهره. لازم نیست چیزی نصب کنید، و برای نصب و کار کردن سامانه
**اینترنت لازم نیست**.

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱ (۶۴ بیتی)
- حدود ۲.۵ گیگابایت فضای خالی

همین. نه Python، نه Docker، نه پایگاه دادهٔ جداگانه.

## نصب

۱. فایل `Hotel-FaceID-Setup-1.3.0.exe` را اجرا کنید و دکمهٔ Next را بزنید.
۲. در پایان، سامانه خودش اجرا می‌شود و **پنل در مرورگر باز می‌شود**.
۳. نام کاربری `admin` و رمز `admin` را وارد کنید.

> **مهم:** بعد از اولین ورود، از منوی «کاربران» رمز admin را عوض کنید.

بار اول چند ثانیه طول می‌کشد تا سامانه بالا بیاید (مدل‌ها در حافظه بارگذاری
می‌شوند). صفحه خودش آماده می‌شود، کاری لازم نیست.

## استفاده روزمره

روی دسکتاپ و در منوی استارت این میان‌برها ساخته می‌شود:

| میان‌بر | کار |
|---|---|
| **Hotel Face-ID** (دسکتاپ) | سامانه را اجرا می‌کند و پنل را باز می‌کند |
| شروع سامانه | همان کار بالا |
| توقف سامانه | سامانه را می‌بندد |
| وضعیت سامانه | نشان می‌دهد سرویس‌ها روشن‌اند یا نه |
| گزارش خطا برای پشتیبانی | یک پوشه گزارش می‌سازد که برای ما بفرستید |

اگر هنگام نصب گزینهٔ «اجرای خودکار هنگام روشن شدن ویندوز» را تیک زده باشید،
سامانه با هر بار روشن شدن سیستم خودش بالا می‌آید.

پنل از روی سایر کامپیوترهای همان شبکه هم باز می‌شود:
`http://<آی‌پی این کامپیوتر>:8000`

## اگر مشکلی پیش آمد

۱. میان‌بر **وضعیت سامانه** را باز کنید — می‌گوید کدام سرویس روشن است.
۲. اگر چیزی روشن نبود، **شروع سامانه** را بزنید.
۳. اگر باز هم درست نشد، **گزارش خطا برای پشتیبانی** را بزنید و پوشه‌ای که
   می‌سازد را برای ما بفرستید.

**پنل باز نمی‌شود؟** ممکن است برنامهٔ دیگری پورت ۸۰۰۰ را گرفته باشد. فایل
`.env` در پوشهٔ نصب را با Notepad باز کنید، `API_PORT=8000` را به عدد دیگری
مثل `8080` تغییر دهید، ذخیره کنید و **توقف** سپس **شروع** را بزنید.

## اطلاعات فنی

سامانه دو سرویس است که هر دو با موتور پایتونِ همراه بسته اجرا می‌شوند:

- **api** — پایگاه داده، منطق ورود/خروج و گزارش‌ها؛ پنل وب را هم سرو می‌کند (پورت ۸۰۰۰)
- **face-service** — اتصال به دوربین‌ها، تشخیص چهره و جنسیت (پورت ۸۰۰۱)

```
C:\HotelFaceID\
├── runtime\python\         ← موتور پایتون همراه بسته (نصب جداگانه لازم نیست)
├── models\buffalo_l\       ← مدل‌های تشخیص چهره، سن و جنسیت
├── .env                    ← تنظیمات (هنگام نصب ساخته می‌شود)
├── data\
│   ├── hotel_faceid.db     ← پایگاه دادهٔ SQLite
│   ├── media\              ← تصاویر چهره
│   ├── logs\               ← لاگ سرویس‌ها
│   └── run\                ← شناسهٔ پروسه‌های در حال اجرا
├── services\               ← سورس کامل بک‌اند (برای دیباگ در دسترس است)
├── web\dist\               ← پنل build‌شده
└── scripts\                ← اسکریپت‌های اجرا و عیب‌یابی
```

### اسکریپت‌ها (برای فرد فنی)

```powershell
.\scripts\start.ps1                  # اجرای سامانه
.\scripts\start.ps1 -NoBrowser       # اجرا بدون باز کردن مرورگر
.\scripts\stop.ps1                   # توقف
.\scripts\status.ps1                 # وضعیت + پاسخ‌دهی API
.\scripts\logs.ps1                   # لاگ زندهٔ API
.\scripts\logs.ps1 face-service      # لاگ زندهٔ سرویس چهره
.\scripts\logs.ps1 api -Errors       # فقط خطاها
.\scripts\debug.ps1                  # بستهٔ گزارش برای پشتیبانی
```

### بکاپ

از پوشهٔ `data\` بکاپ بگیرید — پایگاه داده و همهٔ تصاویر همان‌جاست.
حذف برنامه (Uninstall) این پوشه را پاک نمی‌کند.
