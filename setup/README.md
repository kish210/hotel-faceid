# Hotel Face-ID — نسخه 0.9.0 (آزمایشی)

این نصب‌کننده کل سامانه **تشخیص چهره و مدیریت ورود/خروج هتل** را روی سیستم
مقصد نصب می‌کند. سامانه **بدون Docker** و مستقیماً روی ویندوز اجرا می‌شود.
سورس کامل پروژه همراه نصب می‌شود تا در صورت بروز خطا بتوانید مستقیماً آن را
بررسی/تغییر دهید.

## پیش‌نیازها

- **ویندوز 10/11** (64 بیتی)
- **Python 3.11** — هنگام نصب حتماً گزینهٔ **Add python.exe to PATH** را تیک بزنید
  - دانلود: https://www.python.org/downloads/

> پایگاه داده به‌صورت پیش‌فرض **SQLite** است؛ نیازی به نصب PostgreSQL نیست.
> پنل وب هم توسط خود API سرو می‌شود، پس وب‌سروری لازم نیست.
> Node.js فقط در صورتی لازم است که بخواهید پنل را دوباره build کنید — نسخهٔ
> build‌شده همراه نصب‌کننده می‌آید.

## نصب

1. فایل `Hotel-FaceID-Setup-0.9.0.exe` را اجرا کنید.
2. مسیر نصب را انتخاب کنید (پیش‌فرض: `C:\HotelFaceID`).
3. پس از پایان نصب، از دسکتاپ **"Hotel Face-ID (راه‌اندازی)"** را اجرا کنید.

اسکریپت راه‌اندازی:
- وجود Python 3.10+ را بررسی می‌کند.
- یک محیط مجازی (`.venv`) می‌سازد و وابستگی‌های هر دو سرویس را نصب می‌کند
  (بار اول چند دقیقه طول می‌کشد؛ مدل‌های InsightFace در اولین اجرا دانلود می‌شوند).
- `.env` را از `.env.example` می‌سازد و رمزها را با مقادیر تصادفی امن پر می‌کند.
- هر دو سرویس را در پس‌زمینه اجرا می‌کند.

## پس از نصب

| آیتم | مقدار |
|---|---|
| پنل مدیریت | http://localhost:8000 |
| مستندات API | http://localhost:8000/docs |
| ورود اولیه | `admin` / `admin` — پس از اولین ورود تغییر دهید |

## ساختار نصب‌شده

```
C:\HotelFaceID\
├── .env                    ← تنظیمات (خودکار ساخته می‌شود)
├── .venv\                  ← محیط مجازی پایتون
├── data\
│   ├── hotel_faceid.db     ← پایگاه داده SQLite
│   ├── media\              ← تصاویر چهره
│   ├── logs\               ← لاگ سرویس‌ها
│   └── run\                ← شناسهٔ پروسه‌های در حال اجرا
├── services\
│   ├── api\                ← FastAPI (پنل را هم سرو می‌کند)
│   └── face-service\       ← تشخیص چهره (InsightFace)
├── web\
│   ├── dist\               ← پنل build‌شده
│   └── src\                ← سورس پنل React
├── db\init\                ← اسکیمای PostgreSQL (فقط در حالت اختیاری Postgres)
└── scripts\
    ├── install.ps1         ← نصب/به‌روزرسانی و راه‌اندازی
    ├── start.ps1           ← بالا آوردن سامانه
    ├── stop.ps1            ← پایین آوردن سامانه
    ├── status.ps1          ← وضعیت سرویس‌ها
    ├── logs.ps1            ← مشاهده لاگ زنده
    └── debug.ps1           ← جمع‌آوری لاگ‌ها و اطلاعات عیب‌یابی در یک پوشه
```

## اسکریپت‌های کاربردی

```powershell
.\scripts\start.ps1                  # اجرای سامانه
.\scripts\stop.ps1                   # توقف سامانه
.\scripts\status.ps1                 # وضعیت سرویس‌ها + پاسخ‌دهی API
.\scripts\logs.ps1                   # لاگ زندهٔ API
.\scripts\logs.ps1 face-service      # لاگ زندهٔ سرویس چهره
.\scripts\logs.ps1 api -Errors       # فقط خطاها
.\scripts\debug.ps1                  # بسته لاگ برای ارسال به توسعه‌دهنده
```

## عیب‌یابی

- **"پایتون یافت نشد"**: Python 3.11 را با تیک زدن *Add python.exe to PATH*
  نصب کنید و `scripts\install.ps1` را دوباره اجرا کنید.
- **پنل باز نمی‌شود**: `.\scripts\status.ps1` را ببینید؛ اگر API متوقف است،
  `.\scripts\logs.ps1 api -Errors` علت را نشان می‌دهد.
- **پورت ۸۰۰۰ اشغال است**: در `.env` مقدار `API_PORT` را عوض کنید و
  `.\scripts\stop.ps1` سپس `.\scripts\start.ps1` را اجرا کنید.
- **هر خطای دیگری**: `.\scripts\debug.ps1` را اجرا کنید و پوشه خروجی را برای ما
  بفرستید. سورس کامل در دسترس است و خطای خط مربوطه قابل بررسی است.
